GARANT-ПО v6.0 — универсальная диагностика и установка отсутствующих драйверов
Windows 10 / Windows 11, x64

ГЛАВНОЕ
Предыдущая v5.2 корректно выполнила сканирование (0 проблемных устройств), но её однопоточный локальный HTTP-сервер и браузер не согласовали финальное состояние. В v6.0 локальный сервер переписан на многопоточную .NET-реализацию. Установка драйверов осталась в отдельном PowerShell-процессе.

КАК ЗАПУСТИТЬ
1. Полностью закрой v5.2, включая окно PowerShell. Не открывай сразу две версии.
2. Распакуй v6.0 в отдельную папку, желательно не в Program Files.
3. При необходимости перенеси из v5.2 папки Downloads, Drivers и Cache. Папку State и старые скрипты не переноси.
4. Включи VPN или системный прокси, если он требуется для DRP. При локальном HTTP/SOCKS5-прокси укажи URL в Proxy.txt.
5. Запусти Garant-PO_START.bat от имени администратора. Откроется браузер по http://127.0.0.1:XXXXX/. Командное окно не закрывай.
6. Нажми «Сканировать». Если драйверов не хватает, выбери устройства и нажми «Скачать и установить». Если всё исправно, появится зелёное сообщение.
7. После установки при необходимости перезагрузи Windows и повтори сканирование.

ОТЛИЧИЯ V6.0
- Одновременная обработка запросов к локальному серверу: интерфейс не обязан ждать загрузки или установки.
- Прогресс через EventSource / SSE: актуальный статус каждые ~1 сек, резервный запрос /api/status при обрыве SSE.
- Графический интерфейс показывает этап, имя файла, байты, скорость, долю скачанного файла (если сервер сообщил общий размер) и журнал.
- Автоматическое повторное подключение при временном разрыве.
- Все кнопки работают через локальные маршруты API; ошибки выводятся и логируются.
- Диагностический ZIP формируется в памяти отдельно от установщика.
- «Лог браузера (офлайн)» скачивается без обращения к локальному серверу.
- Повторное сканирование с 0 целей: «Все необходимые драйверы установлены. Проблемных устройств не обнаружено».

ВАЖНО
«Проблемных устройств не обнаружено» НЕ означает, что все установленные драйверы являются самыми новыми версиями. Garant-ПО сканирует разные семейства устройств с отсутствующими драйверами (Code 28), ошибками Диспетчера устройств и Microsoft Basic Display Adapter; применимые обновления Windows Update показываются отдельными строками. Для исправно работающих видеокарт программа не навязывает обновления без подтверждённой версии.

ИСТОЧНИКИ И ВОССТАНОВЛЕНИЕ
Порядок для выбранного устройства: точный и нормализованные Hardware ID проверяются в онлайн-каталоге DRP и локальном каталоге прямых ссылок; в установку допускается только прямой ZIP, а затем INF сверяется с устройством. Пустая страница или HTML вместо архива не считается найденным драйвером. Если DRP не нашёл пакет или оставил устройство проблемным, используются только совпадающие с его Hardware ID предложения Windows Update, если они доступны. Ошибки WU журналируются с HRESULT и не мешают отдельному поиску DRP; при отключённом WU эта ветка пропускается. HTTP 403 и отсутствие пакета в каталоге остаются ограничениями источника, защита сайта не обходится. Кнопка «Источник драйвера» открывает поиск для выбранного устройства, пакет производителя можно установить через «Установить из папки». Для Intel Jasper Lake UHD PCI\VEN_8086&DEV_4E55 доступна автоматическая загрузка официального Intel Graphics пакета с проверкой SHA-512 и Authenticode подписи Intel. Для совместимых NVIDIA/AMD видеокарт открываются сайты производителя; автоматический подбор для них не заявляется без проверки точной модели.

«Включить Windows Update» проверяет wuauserv и BITS; только отключённые службы переводятся в Manual, затем запускаются. Политики Windows Update не меняются. После успешного восстановления нужно повторить сканирование. «Точка восстановления» включает защиту системного тома при необходимости, просит Windows создать точку и проверяет, что она появилась. Windows может ограничивать создание точек интервалом 24 часа; если новая точка отсутствует, UI покажет ошибку, а не ложный успех.

ДИАГНОСТИКА
Logs/Garant-PO-Server.log — запросы/сбои многопоточного HTTP-сервера.
Logs/Garant-PO-Server-Startup-Error.log — ошибки компиляции/запуска .NET-сервера.
Logs/Garant-PO-Interface.log — кнопки и ошибки UI, полученные сервером.
Logs/Garant-PO-Latest.log — сканирование, скачивание, установка.
Logs/Worker-stderr.log, Worker-stdout.log — вывод процесса установщика.
State/status.json, State/devices.json — текущие состояние и устройства.
«Диагностика ZIP» — сбор журналов через браузер.
Garant-PO_COLLECT_LOGS.bat — сбор журналов без браузера.
«Лог браузера (офлайн)» — резервный файл при полной потере связи с сервером.

РЕЗЕРВНЫЕ РЕЖИМЫ
Garant-PO_SCAN_FALLBACK.bat — сканирование напрямую через PowerShell.
Garant-PO_AUTO_FALLBACK.bat — поиск и установка без веб-интерфейса.

ЗАВИСИМОСТИ
Windows PowerShell 5.1, .NET Framework 4.5+ и curl.exe (для онлайн-загрузки), встроенные в актуальные Windows 10/11. Сервер компилируется при запуске через Add-Type из GarantServer.cs; дополнительных приложений и Python не нужно.

СТАТУС КАЧЕСТВА
JavaScript-синтаксис проверен; интерфейс проверен в Chromium на имитации событий SSE: пустой список после сканирования, 50% загрузки (3/6 МБ, 1 МБ/с), завершение и офлайн-выгрузка браузерного лога. Запуск C# через Windows PowerShell, фактическая загрузка драйверов через VPN и установка на клиентских Windows пока НЕ протестированы в этой среде. Считать v6.0 новой тестовой версией до проверки на реальной Windows.
