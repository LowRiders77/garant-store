# Garant Store Next — установочная сборка

Garant Store помогает искать и устанавливать программы из WinGet и Microsoft Store, показывает результаты поиска, ведёт журнал и включает средства диагностики и восстановления WinGet. Раздел «Драйверы» подключает Garant-ПО для совместного поиска устройств с проблемами, обновлений Windows Update и недостающих библиотек.

## Для пользователя

Запустите `GarantStore-Setup.exe` и пройдите мастер установки. Установщик создаёт ярлык в меню «Пуск», предлагает ярлык на рабочем столе и добавляет программу в список установленных приложений Windows. Удалить программу можно через «Параметры Windows → Приложения».

Нужны Windows 10/11 x64 и Windows PowerShell 5.1, который входит в состав Windows. Установка размещается в Program Files и требует права администратора. Для поиска и установки программ нужен WinGet или Microsoft Store; доступность конкретных пакетов зависит от системы и источника.

## Драйверы

Раздел запускает Garant-ПО 6.0 отдельным скрытым локальным сервером и показывает устройства в компактном окне WPF. Сервер слушает только `127.0.0.1`, а обмен состояния использует локальный API/SSE. После сканирования основной список сразу показывает только проблемные устройства и подтверждённые обновления. Полный перечень установленных драйверов и рекомендации компонентов Windows открываются отдельно кнопками в окне; в справочный список не попадают обычные драйверы как кандидаты на замену. Журнал операции скрыт по умолчанию. При сканировании локальные проблемы показываются до сетевых проверок; затем каталог DRP проверяется первым, после него запускается Windows Update как резервный источник. Страницы каталога запрашиваются без Range-докачки, кэш привязан к URL и ОС, а ответ проверяется по HTTP-статусу и типу содержимого; при установке совместимость INF проверяется до запуска pnputil. После установки итоговая проверка учитывает только реальные состояния PnP-проблем, а не справочные записи Inventory. Если WU отключён или не отвечает, он не блокирует работу DRP. Отметьте строки и нажмите «Установить / обновить»; движок последовательно передаст каждый тип своему установщику. Кнопка «Только скачать» сохраняет проверенные ZIP-драйверы, экспортирует загруженные Windows Update пакеты в папку драйверов и скачивает установщики библиотек без их запуска. .NET Framework 3.5 устанавливает сама Windows и скачать отдельно этой кнопкой нельзя. Всё, что движок устанавливает с правами администратора, скачивается, проверяется и распаковывается только в `%ProgramData%\GarantStoreEngine` — папку, которую создаёт сам движок и в которую обычные пользователи не могут писать; при подмене её прав движок не запустится. Копии ZIP-пакетов и экспортированные пакеты Windows Update сохраняются в `%USERPROFILE%\Downloads\Garant Store\Drivers`, копии установщиков библиотек — в `%USERPROFILE%\Downloads\Garant Store\Libraries`. Свои ZIP и INF из папки «Загрузки\Garant Store\Drivers» устанавливаются только кнопкой «Установить из папки»: перед установкой движок делает снимок папки в защищённый каталог (без переходов по ссылкам, до 8 ГБ) и ставит драйверы из снимка. При входе в раздел Windows запросит повышение прав. Связь окна с движком защищена случайным ключом сеанса: окно передаёт его движку при запуске, на диск он не записывается, и без него движок не отвечает ни на один запрос, кроме проверки готовности.

Для восстановления сети программа очищает кэш DNS и сбрасывает каталог Winsock, сохраняя IP-адреса, DNS-серверы и прокси. Перед изменением выводится подтверждение; для применения потребуется перезагрузка Windows. Этот шаг не снимает ограничения брандмауэра, роутера или интернет-провайдера.

Установка скачиваемых библиотек выполняется только после выбора и подтверждения; загрузки проверяются по цифровой подписи Microsoft. Основные компоненты DirectX входят в Windows 10/11, а Legacy-компоненты нужны старым играм и программам.

DRP-поиск работает по нескольким формам Hardware ID для разных семейств устройств; сайт отдаёт прямые ZIP только если в его каталоге есть подходящий пакет для этой ОС. Ответ HTML/JSON или пустая страница никогда не передаются установщику как драйвер. HTTP 403 и отсутствие записи в каталоге остаются реальными ограничениями источника; в таком случае можно проверить совпадающее предложение WU или установить официальный пакет производителя через «Установить из папки». Windows Update показывает только применимые драйверные пакеты из настроенного источника; его ошибки теперь журналируются с HRESULT и не мешают независимому поиску DRP. Отсутствие предложений не доказывает, что на сайтах всех производителей нет более новых версий. Если WU или BITS отключены, отдельная кнопка восстановления меняет только отключённые службы на ручной запуск и запускает их, не меняя политики обновлений. Создание точки восстановления подтверждается проверкой результата; Windows может ограничивать их создание интервалом 24 часа. Windows CI проверяет программную логику, но перед VERIFIED-релизом нужна реальная установка на тестовом ноутбуке с чистой Windows.

## Сборка

Файл `Installer/GarantStoreNext.iss` собирается Inno Setup 6. Автоматическая Windows-сборка проверяет PowerShell 5.1, загрузку WPF, пустое выделение без падения, передачу смешанного выбора драйверов/обновлений/библиотек, восстановление сети, API/SSE, диагностику, отмену Worker, а также установку и удаление программы. Интеграционный gate использует тестовые обработчики и не устанавливает драйверы на оборудование.

Сведения о конфигурации компьютера собираются локально при сканировании. Серийные номера не записываются; локальный отпечаток рассчитывается из аппаратных признаков для разделения истории до 50 последних сессий. Профиль и история добавляются в ZIP диагностики. Доступные измерения времени локального сканирования, инвентаризации, поиска DRP, поиска Windows Update, скачивания и установки сохраняются в статусе и журнале.
