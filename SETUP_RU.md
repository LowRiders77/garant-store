# Garant Store: разовое подключение GitHub

Скрипты Windows CI и публикации уже подготовлены, но ещё не запущены:
в подключённом GitHub нет отдельного репозитория Garant Store. Доступен
только другой проект `rassroschka-ai`, который мы не должны менять.

1. На https://github.com/new создай новый репозиторий `garant-store`.
2. Выбери **Private**, без автоматического README и других файлов.
3. Предоставь подключённому приложению GitHub доступ к новому репозиторию,
   если оно установлено только для выбранных репозиториев.
4. Сообщи, что репозиторий создан. Тогда проект и CI можно загрузить через
   подключённый GitHub без ручного запуска тестов на твоём компьютере.

После загрузки каждое изменение в `main` или `develop` автоматически
проверяется на Windows. Публикация только по отдельному тегу версии
после тестирования исходников и повторного тестирования точного ZIP.

**Тебе больше не нужно запускать Validate-DEV.cmd при каждом обновлении.**

Ограничение: реальную работу WinForms GUI на облачном Windows runner ещё
предстоит проверить; если runner без интерактивного рабочего стола
не сможет показать окно, публикация будет блокироваться до настройки
GUI-capable runner. Непроверенные сборки не получают статус VERIFIED.
